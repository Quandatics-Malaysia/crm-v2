# External development guide

## 1. Prepare a private integration project

Keep integration code in the partner's own private repository. Store the API
key in an environment variable or secret manager:

```bash
export QUANDATICS_API_KEY='qdk_replace_with_sandbox_key'
export QUANDATICS_BASE_URL='https://your-sandbox.example.com'
```

Do not commit `.env`, keys, customer exports, or production responses.

## 2. Create and scope the key

An approved tenant administrator creates a key at **Settings → API Keys**.
Choose a descriptive name and only the required view permissions. Copy the raw
key immediately; the server stores its SHA-256 digest. Revoke and issue a new
key if it is lost or exposed.

## 3. Make a first request

```bash
curl --fail-with-body \
  "$QUANDATICS_BASE_URL/api/v1/accounts?limit=20&offset=0" \
  -H "Authorization: Bearer $QUANDATICS_API_KEY"
```

Responses are tenant-scoped. A record outside the key member's visibility is
returned as `404`, not exposed through a broader query.

## 4. Build safely

- Use `limit` up to `100` and advance `offset` until `pagination.total` is met.
- Treat `401` as missing/invalid key and `403` as insufficient permission.
- Treat `404` as missing or not visible; do not enumerate IDs.
- Add bounded backoff for transient network failures.
- Keep requests server-side; never expose keys in browser JavaScript.
- Do not assume undocumented fields or mutation endpoints.

## 5. Current supported resources

Read [Using the REST API](/api-guide) for the current resource matrix:
leads, accounts, persons, opportunities, funnels, and quotations. The API
playground provides interactive request examples.

## 6. Current limitations

API v1 has no `POST`, `PATCH`, or `DELETE`. Creating records, moving stages,
sending quotations, and editing users remain authenticated application actions.
Write integrations, webhooks, and a public plugin SDK require separate product
approval and are not available by scripting around the UI.

## 7. Delivery to production

Submit the collaboration checklist, sandbox evidence, requested permissions,
data-flow description, and rollback plan to Quandatics. Wait for explicit
production approval. Production credentials are never used during development.
