This directory is derived from application navigation, plugin flags, permission
groups, routes, actions, services, and database schemas. “Module” here means a
business capability. The **Type** column tells you whether it is also a
deployment plugin.

## Cross-cutting code services

These are not sidebar modules, but every contributor should know them:

| Service area | Responsibility |
| --- | --- |
| `server/services/conversion.ts` | Lead conversion into CRM and sales records. |
| `server/services/stage.ts` | Stage movement, validation, approval, and side effects. |
| `server/services/quotation-math.ts` | Quote totals, discount, and tax calculations. |
| `server/services/numbering.ts` | Tenant-scoped project, quote, order, and finance numbering. |
| `server/services/value.ts` | Value synchronization and optional finance callbacks. |
| `server/services/finance.ts` | Project completion from finance state. |
| `server/services/intercompany.ts` | Intercompany mirrors and partner-side behavior. |
| `server/services/activity.ts` | Human-readable record activity. |
| `server/services/changes/*` | Standardized field-level change tracking. |
| `server/services/owner-cascade.ts` | Ownership propagation across related records. |
| `server/services/tenant-seed.ts` | Idempotent tenant defaults and permission setup. |
